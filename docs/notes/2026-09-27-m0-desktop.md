# M0 Desktop Measurement

## Outcome

Both prefix-sharing modes passed the strict probability-difference gate on this fixture set.
Exact mode's maximum absolute difference was `0.0`; batched mode's was `0.000816753403`.
Each mode matched the individual path's top choice on 72 question comparisons, including first and warm calls.
This establishes numerical agreement for these inputs, not classification accuracy or a universal parity guarantee.

Retain individual inference as the baseline and exact sharing for sufficiently long prefixes.
Keep batched sharing experimental: the observed difference is close to the `1e-3` limit, and upstream documents larger differences on other inputs.
M0 is incomplete until a separate iOS measurement exists.

Each row represents one request containing three questions: Choice, Noul, and Score.
Values are request-level warm p50 in milliseconds, including Python rendering and IPC.
Each fixture/mode pair has five warm samples after its first request in a fresh scorer process.
Memory resets before every request prevent reuse of a prior request's prefix.

## Limits and Reproduction

The four fixtures use synthetic English ticket content, including repeated padding to hit exact token counts.
They are not labelled evaluation datasets; no accuracy, calibration, general speedup, or mobile latency claim follows.
The test covers three questions, not the planned 1/5/20-question matrix, sustained load, or broad option counts.
Mode order is fixed and the machine was not isolated from other activity.
Five warm samples per row are insufficient for tail latency or confidence intervals.
First requests and model startup are recorded separately; filesystem and Metal caches are uncontrolled, so these are not cold-device measurements.

Follow the [README commands](../../README.md#m0-desktop-spike) with a new output filename to reproduce the experiment.
The raw [JSON report](2026-09-27-m0-desktop.json) contains 72 request records and every per-question distribution.
The unit suite checks malformed distributions, missing records, empty fixtures, checksum changes, and missing sharing; real inference supplies the parity evidence.
